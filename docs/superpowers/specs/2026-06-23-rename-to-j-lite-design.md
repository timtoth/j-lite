# Rename app to j-Lite

## Goal

Rebrand the user-facing app from "Ticket Control" / "ticket-control" to **j-Lite**, with a Start Menu shortcut name (`jLite`, no hyphen) chosen so typing `jl` in Windows Start Menu search prefix-matches it.

## Identifier strategy

Three distinct names, each picked for what it controls:

| Identifier | Value | Purpose |
| --- | --- | --- |
| `package.json` `productName` | `jLite` | Drives `app.getName()` → `app.getPath('userData')` (= `%APPDATA%\jLite`) and is what Squirrel uses for the Start Menu shortcut. No hyphen so Windows search tokenizes it as a single word and `jl` prefix-matches. |
| `package.json` `name` | `ticket-control` (unchanged) | Internal npm package slug. Keeping it avoids touching npm scripts, the repo directory, and any external references. |
| Window/dialog/HTML title | `j-Lite` | What the user sees in the title bar and in every dialog. Electron lets `BrowserWindow.title` and `dialog.show*` override the product name, so the displayed string can keep the hyphen even though the shortcut doesn't. |

## File changes

### Branding (user-facing)

1. **`package.json`** — add `"productName": "jLite"`. Leave `name` as `ticket-control`.
2. **`forge.config.ts`** — configure `MakerSquirrel` with `name: "jLite"`, `exe: "jLite.exe"`, `setupExe: "jLite-Setup.exe"` so the installer and Start Menu shortcut are named `jLite`.
3. **`client/index.html`** — `<title>j-Lite</title>`.
4. **`electron/main.ts`**
   - `new BrowserWindow({ title: "j-Lite", ... })` so the window title bar shows `j-Lite`.
   - Replace the three `"ticket-control"` strings in dialog titles (lines 83, 114, 198) with `"j-Lite"`.

### Docs / scripts

5. **`CHECKLIST.md`** — heading `# j-Lite - Task Checklist`.
6. **`setup.ps1`** — banner text → `j-Lite - Windows Setup`.
7. **`setup.sh`** — banner text → `j-Lite Setup`.
8. **`install-startup.bat`** — `TASK_NAME=jLite` and the comment line.
9. **`CLAUDE.md`** — update the opening references that describe the product to `j-Lite`. Leave technical references to internal paths/files (e.g. `ticket-control/`) alone since the repo dir name is unchanged.

- `client/package.json` `name` — internal slug.

## One-time userData migration

Renaming `productName` changes Electron's userData directory. Before:

```
%APPDATA%\ticket-control\config.json
%APPDATA%\ticket-control\app.log
```

After:

```
%APPDATA%\jLite\config.json
%APPDATA%\jLite\app.log
```

**Migration logic** (in `electron/main.ts`, before `startServer()` runs):

- `newDir = app.getPath('userData')` (= `%APPDATA%\jLite` once `productName` is set).
- `oldDir = path.join(app.getPath('appData'), 'ticket-control')`.
- If `newDir/config.json` does **not** exist AND `oldDir/config.json` **does** exist:
  - `fs.mkdirSync(newDir, { recursive: true })`.
  - Copy `config.json` (and `app.log` if present) from `oldDir` to `newDir`.
  - Log the migration via the existing `logger` so there's a trace.
- Otherwise: do nothing.

The check is idempotent — once `newDir/config.json` exists, the next launch is a no-op. Existing fresh installs (no old dir) are also a no-op.

## Testing

- **Unit:** `node --test` continues to pass. No new pure helpers needed; the migration runs once at startup and is wired directly in `main.ts`.
- **Dev (`npm start`):** title bar shows `j-Lite`. Server-restart dialog title shows `j-Lite`. Note that `app.getName()` returns `productName` when set (in both dev and packaged), so `app.getPath('userData')` resolves to `%APPDATA%\jLite` in dev too — meaning the migration runs in dev on first launch after the rename, not just in the packaged build.
- **Packaged (`npm run make`):**
  - Installer file: `out/make/squirrel.windows/x64/jLite-<ver> Setup.exe`.
  - After install, Start Menu shortcut is named `jLite`.
  - Pressing the Windows key and typing `jl` surfaces the shortcut.
  - First launch with a pre-existing `%APPDATA%\ticket-control\config.json` produces `%APPDATA%\jLite\config.json` with the same contents.
  - Second launch is a no-op (verified by adding a marker to the new file and confirming it isn't overwritten).
